# 对照概念图：建模优化提案

当前工作副本是 **v2-paint**（白模上色第一轮）。问题不是“没涂色”，而是机械语言不完整：光滑白球 + 橙耳 + 橙圈，看起来像玩具，不像概念图里的工业球体。

概念图的机械感来自五件事叠在一起：**分件、开槽、橙带、镜头光学、开窗内构**。只改颜色解决不了。

## 建议保留

- 球体壳体 + CSG 挖镜头井 / 颞侧窗 / 底部通风口
- 锐角猫耳、耳根埋进球面
- 三道顶纹节奏、镜头当眼睛、颞侧开窗、侧舱、螺丝语言
- 白模 v1 已冻结，后续只做加法

## 建议改（按优先级）

### P0 形体 — 不上色也该像机械

1. **装甲分件 / 板缝**  
   现在壳体是一整颗光滑球。概念图用板缝把球面切成额板、颊板、下颚板、侧板。机械感主要来自这里，不是来自灰漆。

2. **橙色环带（识别度最高的图形）**  
   概念图有两条：  
   - 上带：从左颞窗穿过面颊到右颞窗，像眉/胡须  
   - 下带：镜头下方的嘴形橙条  
   现在完全没有。没有这两条，上色再准也认不出来。

3. **镜头组，不要黑球 + 橙环**  
   概念图是多层光学镜头（镀膜、光圈环、内陷暗井）坐在切面/六边面板上。现在是橙色圆环套一颗高光黑球。

4. **顶纹改成凹陷槽**  
   现在是贴在球面上的凸管，像三根香肠。概念图是壳体上刻进去的三条猫纹。

### P1 内构与贴合

5. **颞侧开窗露出内构**  
   现在是黑盒子 + 两颗螺丝。概念图能看到活塞、线束、橙带从窗里穿过去。

6. **侧舱贴合球面**  
   现在是方盒子。概念图是顺着球面长的机械舱，有圆口和细缝。

7. **下巴进气格栅加深**  
   概念图底部是真正的进气口，不是五个小方块。

8. **螺丝跟着板缝走**  
   现在螺丝是撒在球面上的。应该钉在板角和开窗边缘。

### P2 材质与光

9. **工业灰，不是白塑料**  
   概念图是偏冷的中灰（大约 `#5c6168`），缎面漆。现在 `#d2d5da` + Phong 自发光，还是粘土。

10. **PBR 分层**  
    `MeshPhysicalMaterial` + 环境反射：灰漆低金属/中粗糙，橙漆略亮，螺丝拉丝钢，镜头玻璃高 IOR。Phong 做不出这个。

11. **耳腔内壁更深**  
    概念图内耳是暗橙网纹，外耳是安全橙。现在内外都偏亮。

## 建议版本顺序

| 版本 | 做什么 | 为什么先做 |
|---|---|---|
| **v2-paint** | 初步上色（已冻结） | 回退点 |
| **v3-panels** | 板缝 + 两条橙带 + 顶纹改凹陷（已冻结） | 识别度 |
| **v4-lens** | 切面额板 + 多层镜头组 | 脸部中心 |
| **v5-guts** | 颞窗内构、侧舱、进气口、螺丝归位 | 机械密度 |
| **v6-pbr** | 工业灰 / 橙漆 / 钢 / 玻璃 + 环境光 | 质感收口 |

v3 已冻结。下一步是 v4-lens。材质收到 v6。

## 明确不做（沿用 v1 取舍）

圆肩、头上圆盘、额外箍带、眼睑、支撑脚。镜头箍保留。
